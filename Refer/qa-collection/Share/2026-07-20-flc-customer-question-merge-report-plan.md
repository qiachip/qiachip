# FLC 客户问题合并报告实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将已分类 FLC 客户问题按宽口径核心功能合并，生成内容结构完全对应的中文报告和英文报告。

**架构：** 以 Excel 的 `分类` 列、已批准多标签索引和双语问题列为输入。先固定主题到 ID 和型号的映射，再写中文主报告，最后逐节生成英文镜像报告，并自动核对两份报告的标题、ID、型号和待分类附录。

**技术栈：** Markdown、Python `openpyxl` 只读解析、PowerShell/文本搜索验证。

---

### 任务 2：生成中文宽口径报告

**文件：**
- 创建：`Refer/qa-collection/Share/FLC_Customer_Question_Merge_Report_ZH_2026-07-20.md`

- [ ] **步骤 1：编写报告说明和合并原则**

说明本报告只合并客户问题，不提供答案；按核心功能宽泛合并；不同型号只合并客户意图，不默认技术规格相同。

- [ ] **步骤 2：按固定顺序编写 12 个主题**

每个主题必须包含：

```text
来源索引
涉及型号
合并逻辑
合并后的问题
后续分析重点
```

`风速` 的合并问题固定使用宽口径：

```text
为什么安装 FLC 风扇控制器后，LOW、MED、HI 三档风速与预期不匹配？
```

其他主题使用同等粒度：描述核心功能异常，不在问题中罗列每一种具体症状。

- [ ] **步骤 3：处理单条来源主题**

`停电后恢复`、`三年后有问题`、`改进建议`、`线太短` 只有一条主要来源。明确标记为“单独保留”，不声称完成了多条合并。

- [ ] **步骤 4：添加待分类附录**

列出 ID `10,39,94,116,119,121,136,142` 的型号和一句话问题摘要。烧毁记录 ID `39` 和 `121` 标记为安全事件，不直接转成普通公开 FAQ。

### 任务 3：生成英文镜像报告

**文件：**
- 创建：`Refer/qa-collection/Share/FLC_Customer_Question_Merge_Report_EN_2026-07-20.md`

- [ ] **步骤 1：镜像中文报告结构**

保持相同主题顺序、ID、型号、合并关系、单独保留决定和待分类附录。

- [ ] **步骤 2：编写简明英文**

使用简单词、短句和明确对象。英文合并问题保留 `LOW`, `MED`, `HI`, `receiver`, `remote`, `light`, `buzzer` 等客户搜索词，不添加中文报告中不存在的技术结论。

- [ ] **步骤 3：核对风速问题的英文粒度**

使用：

```text
Why do the LOW, MED, and HI fan speeds not match expectations after installing the FLC fan controller?
```

不得继续拆成低速过快、中速异常或高速失效等独立 FAQ。

- [ ] **步骤 2：验证双语索引一致**

- [ ] **步骤 3：验证来源覆盖**
